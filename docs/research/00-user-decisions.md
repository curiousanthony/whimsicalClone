# User decisions (authoritative, override anything else in research or prompts)

- **Drawing is for sketching ideas and diagrams, not art.** Minimalist pen like Whimsical's: smooth simple strokes, a few colors/widths, eraser, undo. **NO pen-pressure / tablet pressure sensitivity handling needed** (constant-width strokes; perfect-freehand may still be used for smoothing, with pressure ignored). Pointer Events with pen input should still work as a plain pointer.
- Wireframes and Boards (sticky notes, text, shapes, connectors, images, pen) are required, with the same toolset as Whimsical.
- Icons: lucide-react only.
- UI in English, i18n from day one (French later).
